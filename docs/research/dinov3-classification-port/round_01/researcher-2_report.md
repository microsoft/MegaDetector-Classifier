## Sub-area: target-architecture

## Key Findings

1. **[NEW] Base inference is a convention, not an enforced abstract interface.** Verified: `BaseClassifierInference` subclasses `nn.Module`, but `results_generation`, `forward`, `single_image_classification`, and `batch_image_classification` are empty stubs with no argument contract enforced at the base layer (`src/models/classification/base_classifier.py:11-29`). **Implication:** a DINOv3 family can safely subclass `BaseClassifierInference`, but must match the concrete subclass method contracts used by current users.

2. **[NEW] ResNet inference contract is fixed around `PlainResNetInference(weights, device, url, transform, num_cls, num_layers)`, not `_load_model`.** Verified: `PlainResNetInference` defines `IMAGE_SIZE = None`, constructs `PlainResNetClassifier`, loads either local `weights` via `torch.load` or remote `url` via `load_state_dict_from_url`, requires `clf_weights["state_dict"]`, and raises `Exception("Need weights for inference.")` without either (`src/models/classification/resnet_base/base_classifier.py:105-127`). It implements `forward`, single-image path/array inference, and batch inference over `ImageFolder`/`DetectionCrops` (`src/models/classification/resnet_base/base_classifier.py:143-193`). **Implication:** do not retrofit `_load_model` into ResNet base or change checkpoint key semantics.

3. **[NEW] Existing ResNet classifier subclasses define public names, class attrs, constructors, and result schemas that DINOv3 must not disturb.** Verified: `AI4GAmazonRainforest` has `IMAGE_SIZE=224`, 36 `CLASS_NAMES`, constructor `weights=None, device="cpu", pretrained=True, version="v2"`, Zenodo URL selection, and softmax result dicts with `img_id`, `prediction`, `class_id`, `confidence`, `all_confidences` (`src/models/classification/resnet_base/amazon.py:14-115`). `AI4GOpossum` is binary sigmoid/threshold with two class names (`src/models/classification/resnet_base/opossum.py:14-72`); `AI4GSnapshotSerengeti` is 10-class ResNet-18 softmax (`src/models/classification/resnet_base/serengeti.py:14-85`); `CustomWeights` derives class count from `class_names` and loads ResNet-50 custom weights (`src/models/classification/resnet_base/custom_weights.py:14-67`).

4. **[NEW] `TIMM_BaseClassifierInference` is the closest existing extension pattern for a DINO-style transformer classifier.** Verified: it defines class attrs `BACKBONE`, `MODEL_NAME`, `IMAGE_SIZE`; constructor `weights=None, device="cpu", url=None, transform=None, weights_key='model_state_dict', weights_prefix=''`; default transform by `IMAGE_SIZE`; `_load_model` creates a `timm` model, downloads URL weights to `torch.hub.get_dir()/checkpoints` with `wget`, strips a checkpoint key prefix, and moves `self.predictor` to device (`src/models/classification/timm_base/base_classifier.py:23-103`). Its `results_generation`, `single_image_classification`, and `batch_image_classification` provide a working PytorchWildlife-style template (`src/models/classification/timm_base/base_classifier.py:104-211`).

5. **[NEW] Current transformer-family concrete classes are DINOv2/timm-only and additive.** Verified: `DeepfauneClassifier` and `DFNE` subclass `TIMM_BaseClassifierInference`, set `BACKBONE="vit_large_patch14_dinov2.lvd142m"`, `MODEL_NAME`, `IMAGE_SIZE=182`, and classifier class names; Deepfaune also overrides the transform with bicubic resize and a language-selected class map (`src/models/classification/timm_base/Deepfaune.py:20-48`; `src/models/classification/timm_base/DFNE.py:18-57`). **Implication:** DINOv3 should be a new `dinov3_base` family, not a mutation of `timm_base` DINOv2 behavior.

6. **[NEW] SpeciesNet is intentionally optional and uses a separate inference shape.** Verified: `speciesnet_base/__init__.py` catches `ImportError` so importing `classification` still succeeds without `speciesnet` (`src/models/classification/speciesnet_base/__init__.py:1-4`); `SpeciesNetTFInference` imports `speciesnet` inside `__init__`, raises an actionable install error, builds a Kaggle model URL, and classifies by file/folder via `SpeciesNet`, not the local DataLoader contract (`src/models/classification/speciesnet_base/speciesnet_tf.py:18-49`, `src/models/classification/speciesnet_base/speciesnet_tf.py:74-103`). **Implication:** DINOv3-only dependencies should use optional imports/actionable errors or declared extras so existing imports keep working.

7. **[NEW] `dinov3_base` currently has no source `.py` implementation to preserve.** Verified: directory view shows only `__pycache__` under `src/models/classification/dinov3_base/`; a `find src/models/classification -maxdepth 4 -type f` command showed only `.pyc` files in that folder and no `.py` files. **Implication:** adding `dinov3_base/__init__.py`, `base_classifier.py`, and an Amazon loader is a safe additive extension if existing package exports are not removed.

8. **[NEW] Batch inference data contract is `(tensor, path)` from both image folders and detection crops.** Verified: `ImageFolder` walks allowed image extensions and returns `img, img_path` (`src/data/datasets.py:20-72`); `DetectionCrops` expects detector result dicts with `det["detections"].xyxy`, `det["detections"].class_id`, and `det["img_id"]`, filters to `animal_cls_id`, crops with `supervision`, applies transform, and returns `img, img_path` (`src/data/datasets.py:164-221`). Both ResNet and TIMM batch classifiers consume `imgs, paths = batch`, concatenate logits/paths, and call `results_generation` (`src/models/classification/resnet_base/base_classifier.py:157-193`; `src/models/classification/timm_base/base_classifier.py:158-211`).

9. **[NEW] The classification inference transform is fixed square resize plus ImageNet normalization.** Verified: `Classification_Inference_Transform(target_size=224, **kwargs)` composes `Resize((target_size, target_size), **kwargs)`, `ToTensor`, and `Normalize(mean=[0.485,0.456,0.406], std=[0.229,0.224,0.225])` (`src/data/transforms.py:123-158`). **Implication:** DINOv3 should either keep this default for old families unchanged or define a DINOv3-specific transform in the new family without changing `Classification_Inference_Transform` behavior globally.

10. **[NEW] Training is configured by YAML strings resolved through module `__dict__` registries.** Verified: `main.py` loads YAML into `Munch`, mutates mode flags, runs optional split/crop preprocessing, then constructs `dataset = datasets.__dict__[conf.dataset_name](conf=conf)` and `learner = algorithms.__dict__[conf.algorithm](...)` (`main.py:67-111`). The default config binds `algorithm: Plain`, `dataset_name: Custom_Crop`, `model_name: PlainResNetClassifier`, and ResNet hyperparameters (`configs/config.yaml:1-40`). `Plain` then resolves `models.__dict__[self.hparams.model_name]` (`src/algorithms/plain.py:30-47`). **Implication:** DINOv3 embedding-file training should add new registry symbols/config files, not rename `Plain`, `Custom_Crop`, `PlainResNetClassifier`, or alter `configs/config.yaml` defaults.

11. **[NEW] Existing training batches and model interface are ResNet-feature/classifier oriented.** Verified: `Custom_Crop_DS` emits `(sample, file_id)` for prediction and `(sample, label_id, label, file_dir)` otherwise (`src/datasets/custom.py:110-160`); `Custom_Base` builds train/val/test/predict dataloaders and exposes `id_to_labels` plus `train_class_counts` (`src/datasets/custom.py:163-237`). `Plain` expects `self.net.feature`, `self.net.classifier`, `.feat_init()`, and `.setup_criteria()` (`src/algorithms/plain.py:45-80`), uses batch indexes for train/val and full tuples for test/predict, and already saves `feats`, `logits`, and `file_ids` to `.npz` in test/predict paths (`src/algorithms/plain.py:81-243`). **Implication:** the two-stage DINOv3 workflow should use a new embedding dataset/linear algorithm or model wrapper instead of forcing embedding files through `Plain`'s ResNet image path.

12. **[NEW] Public exports, dependency declarations, and tests are fragile surfaces.** Verified: `src/models/__init__.py` exports `PlainResNetClassifier` and `classification` (`src/models/__init__.py:1-2`); `classification/__init__.py` re-exports `resnet_base`, `timm_base`, `speciesnet_base`, and `base_classifier` (`src/models/classification/__init__.py:1-4`); family `__init__` files re-export concrete classes (`src/models/classification/resnet_base/__init__.py:1-5`; `src/models/classification/timm_base/__init__.py:1-4`; `src/models/classification/speciesnet_base/__init__.py:1-4`). Runtime deps include `PytorchWildlife`, `lightning`, `timm`, `wget`, `supervision`, `Pillow`, and `tqdm`, but not `transformers` or `peft` (`requirements.txt:1-11`; no `rg` matches for `transformers|peft` in requirements/env/lock/src). Python constraints conflict across README 3.9+, conda 3.8.18, and `uv.lock` >=3.10 (`README.md:60`; `environment.yaml:22`; `uv.lock:1-3`). Source test files are absent in `tests/`, but `.pytest_cache` lists prior DINOv3/invariant node ids (`.pytest_cache/v/cache/nodeids:1-46`).
